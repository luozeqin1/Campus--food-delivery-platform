**② 项目最终名称**

      中文：校园智能外卖配送服务平台

      英文：Campus Smart Food Delivery Service Platform

  ③ 核心目标用户

       在校学生：便捷点餐、代取餐、拼单省钱

       校园周边商家：线上接单、订单管理、精准触达学生客群

     校园配送员：接单跑腿、收益结算、路线规划

     学校后勤管理方：监控外卖安全、规范配送秩序

 ④ 核心系统功能

 1. 在线点餐与支付：浏览商家、选餐下单、支持微信 / 支付宝支付

 2. 智能拼单与代取：同楼 / 同寝拼单减配送费，代取餐服务匹配

 3. 实时订单跟踪：展示骑手位置、预计送达时间、订单状态更新

 4. 商家与订单管理：商家端接单、菜品上下架、营收数据统计

 5. 校园配送调度：智能分配订单、优化配送路线、超时预警

⑤ 拟采用技术栈

    前端：微信小程序 + Vue 3 + Vant UI（适配移动端）

    后端：Spring Boot + MyBatis-Plus • 数据库：MySQL（存储用户、商家、订单数据）

    实时通信：WebSocket（订单状态、位置推送）

   地图服务：高德地图 API（路线规划、位置跟踪）

   部署：阿里云 ECS + Nginx + Docker
